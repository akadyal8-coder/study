# StudyFlow AI — Zero Cost Edition (20)
نسخة ثابتة لا تحتاج خادم AI أو مفتاح API أو فوترة. يستخدم مساعد الدراسة ChatGPT في نافذة منفصلة بحسابك الحالي، وفق حدود حسابك.
## النشر
فك الضغط وارفع الملفات إلى جذر مستودع GitHub عام، ثم Settings → Pages → Deploy from a branch → main → / (root). أو استخدم GitHub Actions المرفق. افتح رابط Pages في Safari ثم مشاركة → إضافة إلى الشاشة الرئيسية.
## الذكاء الاصطناعي
اختر الأداة والمادة، جهز الطلب وانسخه، افتح ChatGPT والصق الطلب وارفع PDF أو الصور هناك عند الحاجة. انسخ الرد إلى التطبيق واحفظه أو استورد JSON للأسئلة أو البطاقات. راجع الإجابات قبل الاعتماد عليها. لا يتم إرسال الملفات أو البيانات تلقائيًا. حدود ChatGPT ورفع الملفات تعتمد على حسابك.
## البيانات والاختبار
صدّر نسخة احتياطية شاملة قبل التحديث، وحافظ على عنوان الموقع نفسه. لا ترفع بياناتك الشخصية أو النسخ الاحتياطية إلى مستودع عام. اختبر المؤقت والملفات والاستيراد على الآيباد قبل الاعتماد عليه. npm test يفحص الصياغة وملفات الأيقونات فقط؛ لم يتم اختبار Safari أو ChatGPT فعليًا.
